  callers, both covered: the single-student TC page

  (`documents/page.js` `handlePrintTc`/`tcPreviewRow`) — both pass a
  `mapToStudent()`-shaped object that already carries `.lastName`.

  `TC_FIELDS`, admin uploads a spreadsheet with its own Father's/Mother's
  Name columns) — those are already admin-typed free text, not derived
  from a student record, so the gap this fix addresses doesn't apply there.
