# LOG-2026-09-28 — Transfer Certificate redesign & generator aligned with reference PDF

## What I set out to do

You requested:
1. "go to document tc section the genrated tc will should look like LAKSHITA RAULA TC.pdf"
2. "push"

The goal was to align the Transfer Certificate (School Leaving Certificate) generation across the Admin Panel (`/documents` and individual `/student/[id]/tc`) with the exact layout, header emblems, typography, 18+ numbered fields with continuous baseline fill-ins, warning notice, and 3-column signature block seen in the physical school document `LAKSHITA RAULA TC.pdf`.

## What I did

1. **Extracted and Embedded Emblem Assets:**
   - Extracted high-resolution transparent logos from `LAKSHITA RAULA TC.pdf`:
     - School Crest: `admin-panel/public/tc-logo.png`
     - Shree Shree Maa Saraswati: `admin-panel/public/tc-saraswati.png`
   - Created `admin-panel/src/lib/tcAssets.js` containing base64 data URLs to guarantee instant, reliable rendering in popup print windows and offline exports without network latency or path resolution issues.

2. **Built Shared Certificate Engine (`admin-panel/src/lib/tcGenerator.js`):**
   - Created pixel-precise HTML/CSS template matching the reference PDF:
     - 4-line school title header with affiliated DISE code bar (`Affiliation No. 1530325`, `School Code: 16120`, `DISE Code: 21193101502`).
     - Maroon pill badge: `TRANSFER CERTIFICATE (SCHOOL LEAVING CERTIFICATE)`.
     - 4-slot metadata bar: `Book No.`, `Sl. No.`, `Admission No.`, `Date of Issue`.
     - Full 18 standard fields formatted with `tc-fill-row` and continuous dotted baseline fill-ins.
     - Word conversion helper for Date of Birth (`dobParts` parses day, hyphenated word, year).
     - Standard caution notice: `N.B.:- Any change or cutting on the body of certificate makes it invalid.`
     - Three signature blocks: `Checked By / Office Clerk`, `Signature of Class Teacher`, and `Principal (With Seal)`.
   - Exported single and batch certificate generators with complete `@media print` styling (`@page { size: A4 portrait; margin: 8mm; }`).

3. **Revamped Documents TC Management (`admin-panel/src/app/(dashboard)/documents/page.js`):**
   - Added dual input modes:
     - **Select Students:** Browse active enrolled roster with class/section filters and multi-select.
     - **Bulk CSV / Excel Import:** Downloadable template and parser for issuing external or offline batch certificates.
   - Added Certificate Issuance Options toolbar: Serial No. prefix/start, Issue Date override, Reason for Leaving, and Remarks.
   - Built interactive live preview (`TcPreview`) with responsive zoom scale and pagination controls (`<` `>`) allowing administrators to inspect the exact printable certificate before generating.
   - Wired batch and single print handlers opening a sanitized print window.

4. **Synchronized Individual Student TC (`admin-panel/src/app/(dashboard)/student/[id]/tc/page.js`):**
   - Replaced old generic TC template with the new shared generator so that single-student issuance from the Student profile produces the identical document.

5. **Build Verification & Deployment:**
   - Ran `npm run build` in `admin-panel` — exited code 0, 46/46 static routes rendered cleanly without lint or compilation errors.
   - Committed changes: `dc3f507` — `feat(documents): align transfer certificate layout and generator with reference PDF`.
   - Pushed cleanly to `origin/main` (`https://github.com/sectofficework-droid/SATYAM-SCHOOL.git`).

6. **Full-Page Height & Text Alignment Calibration (User Feedback Follow-up):**
   - User reported certificate was taking up only half an A4 page vertically and inserted text alignment had spacing discrepancies.
   - Refactored `.tc-page` and `.tc-cert-box` to explicitly command full A4 height (`297mm`) with `display: flex; flex-direction: column; justify-content: space-between;`, distributing all 18 rows evenly across the entire vertical space without artificial truncation or blank bottom space.
   - Replaced fragile non-breaking space hacks with fixed-width two-sided colon column alignment (`.tc-col-lbl` at `220px`), ensuring colons across rows 1-6, 8, 9 align at the identical horizontal mark.
   - Fixed baseline alignment of inserted values (`.tc-line`) with centered uppercase text sitting gracefully 1px above the 1.2px solid underline.
   - Upgraded multi-part examination, promotion, and attendance rows with continuous trailing baseline underlines extending to the right border.
   - Synchronized `TcPreview` container and scale (`0.3715`) to perfectly display the full-height certificate without cropping.
   - Verified via `npm run build` (clean 46/46 pages).

7. **Font Size & Proportions Optimization (User Feedback Follow-up):**
   - User noted that while A4 page height was fixed, font size was unoptimized and appeared too small for the physical A4 page.
   - Scaled up font hierarchy across the entire certificate:
     - School name: `25px` -> `30px` (Times New Roman, bold, commanding title).
     - Trust name: `13.5px` -> `15.5px`.
     - School address: `12.5px` -> `14px`.
     - Title pill: `19px` -> `23px` with `5px 42px` padding and `2.2px` solid border.
     - DISE code: `13.5px` -> `15.5px` bold.
     - Field labels: `13px` -> `14.8px` / `15px` (`.tc-col-lbl` width expanded from `220px` to `245px` to cleanly house all labels and colons).
     - Inserted text values: `13px` -> `15px` bold uppercase on `1.4px` solid underlines.
     - Signature block: `13.5px` -> `15px` labels, Principal title `16.5px` bold.
     - Rustication warning note: `10px` -> `11.5px` legible notice.
     - Emblems: scaled up from `64x72px` / `54x72px` to `74x82px` / `62x82px`.
   - Verified via `npm run build` (clean 46/46 pages).
