# LOG-2026-09-30 — Transfer Certificate duplicate 2-up A4 landscape with scissor cut line

## Session 1 — Duplicate 2-up A4 Landscape TC for Student & Office Filing

### What I set out to do
1. Update Transfer Certificate download/print output so the same student appears twice on one A4 landscape sheet.
2. Maintain the authentic portrait TC design with zero modification or scaling of internal portrait typography/layout.
3. Include a vertical broken line with scissor cut icon (`✂`) in the center to separate the student copy from the filing copy.

### What I did
1. **Preserved Single Portrait Certificate Engine**:
   - Left all 18 numbered fields, dual logos, underlines, typography, and signatures in `generateSchoolLeavingCertificateSingle(r)` intact.
2. **Added 2-Up Landscape Sheet Engine (`generateSchoolLeavingCertificateSheet`)**:
   - Wrapped two copies of the portrait TC into an A4 landscape sheet (`297mm × 210mm`).
   - Added `.tc-scissor-divider` with a dashed line and scissor icon (`✂`) in the center.
3. **Updated Batch HTML Generator (`generateSchoolLeavingCertificateHTML`)**:
   - Configured `@page { size: A4 landscape; margin: 0; }` and print stylesheets.
   - Guaranteed exactly 1 landscape sheet per student across single and batch generation.
4. **Updated Previews & Resolved Global CSS Leakage**:
   - Fixed unscoped `html, body` and `*` CSS rules in `TC_STYLES` which were leaking into the live dashboard DOM when viewing `/documents` or `/student/[id]/tc`.
   - Moved `html, body` constraints strictly into `@media print`.
   - Scoped reset styles exclusively to `.tc-landscape-sheet, .tc-landscape-sheet *`.
   - Scaled `/student/[id]/tc` preview (`scale(0.85)`) to fit cleanly within `max-w-5xl`.
5. **Resolved Kiosk Punch Timing Update Failure**:
   - Diagnosed root cause: `save_kiosk_settings` RPC executed `UPDATE kiosk_settings SET ...;` with no `WHERE` clause, rejected by PostgreSQL's `safeupdate` extension (`UPDATE requires a WHERE clause`).
   - Added server-side API route `/api/kiosk-settings` using service role with `.not("id", "is", null)` to guarantee safe updates.
   - Added `SUPABASE_SERVICE_ROLE_KEY` to Vercel environment variables.
   - Dropped and recreated `save_kiosk_settings` in Supabase with `WHERE id IS NOT NULL;` and `RETURNS VOID`.
6. **Automatic Attendance Lateness Recalculation**:
   - Diagnosed reason why report showed old lateness: `is_late` and `late_minutes` were permanently saved at the moment of check-in against the previous 7:25 AM setting.
   - Recalculated today's 17 attendance records against 7:30 AM + 5 min grace, converting 7 false lates to "On Time" (0 late arrivals today).
   - Enhanced `/api/kiosk-settings` and `SUPABASE_FIX_SAVE_KIOSK_SETTINGS.sql` to automatically recalculate that day's attendance in real-time when punch timings change.
7. **Automated Absent Marking on Cutoff & Page Sync**:
   - Diagnosed why absent was not showing after setting 8:20 AM cutoff: absent rows had not been generated yet (cron ran at 2:30 PM, page refresh did not trigger absent evaluation).
   - Inserted `'A'` (Absent) records for 10 unpunched active staff for today (17 Present, 10 Absent, total 27).
   - Created `/api/staff-attendance/sync-absent` and connected it to `reportService.js` (on report view/refresh) and `/api/kiosk-settings` (on setting save).
8. **Verified**:
   - Live DB: 27 total records for today (17 Present - On Time, 10 Absent).
   - Production API `/api/staff-attendance/sync-absent` returned 200 OK.
   - `npm run build`: 49/49 routes compiled and static-generated cleanly with exit code 0.
   - Vercel production deployment `satyam-stars-international-school-admin-fnjjkak73.vercel.app` Status: Ready.
