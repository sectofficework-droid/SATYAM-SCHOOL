# LOG 2026-10-19 — Notebook module + marks report

## What I set out to do
Add a new "Notebook" feature to the Teacher app: a quick way for a teacher
to mark, per class and per date, whether each student's notebook work is
complete — defaulting to "complete" and only unticking the exceptions.
Partway through, also add a way to see a running marks total (10 marks per
tick) across different dates.

## What I did
- Built the Notebook grid in the Teacher app: pick a class, pick a date
  (today by default), see every student down the side and every subject of
  that class across the top, tap any cell to tick/untick it — it saves
  itself the instant you tap, no Save button needed.
- Built a Notebook Report screen (reachable from the grid's top-right
  icon) showing, for a class and a date range, how many marks each student
  earned per subject and overall.
- Added the same report to the admin panel (Reports → Notebook), with an
  Excel export.
- Set up the new database table and the three small server functions this
  all runs on, and applied them to the live database.

## Decisions
- Any teacher can open any class (not just their own homeroom) — you
  corrected me on this partway through.
- The grid shows every subject at once, not one-subject-at-a-time like the
  existing Daily Progress feature.
- The date defaults to today but can be changed to any of the last 60
  days.
- Marks (10 per tick) are calculated on the spot from the tick history —
  nothing new is stored for marks, so there's nothing extra to keep in
  sync.
