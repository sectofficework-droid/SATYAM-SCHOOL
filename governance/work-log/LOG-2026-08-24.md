# LOG-2026-08-24

## What I set out to do
Add a way to bulk-import students with just the basics (class, name,
parents' names, DOB, mobile numbers, address) instead of needing every
field up front — get them a working enrollment number and app login right
away, then fill in the rest later in a batch. Also needed a way to spot
which students still only have the basic info.

## What I did
- New "Import Basic Details" button on the Student page — download a
  template, fill it in, upload it, and it creates the students with
  enrollment numbers assigned automatically.
- New "Replace Full Details" tool in Super Admin — a second import that
  matches students by their enrollment number and fills in/overwrites their
  full details once you've collected them.
- Student list now shows an "Incomplete" tag on any student added via the
  basic import, plus a filter to see just those students, so it's obvious
  who still needs full details entered.
- Filling in the rest of a student's details — either through the new
  Replace Full Details import or just editing them normally on the Edit
  Student page — automatically clears that "Incomplete" tag.

## Decisions
- New students from the basic import go into section "A" by default, same
  as the regular Add Student form already does.
- No extra work was needed for app login — new students already get a
  working default password the same way the regular Add Student form's
  students do.
